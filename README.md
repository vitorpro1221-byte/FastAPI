# FastAPI - Estudos

Repositório com meus estudos práticos sobre o framework **FastAPI**, construindo uma API simples de gerenciamento de livros.

## 📖 Sobre o projeto

Este projeto é uma API REST para cadastro e consulta de livros, desenvolvida como exercício de aprendizado do FastAPI e do Pydantic v2.

## 🚀 Tecnologias

- [Python 3](https://www.python.org/)
- [FastAPI](https://fastapi.tiangolo.com/)
- [Pydantic v2](https://docs.pydantic.dev/latest/)
- [Uvicorn](https://www.uvicorn.org/) (servidor ASGI)

## 📦 Instalação

```bash
# Clone o repositório
git clone https://github.com/vitorpro1221-byte/FastAPI.git
cd FastAPI

# Crie um ambiente virtual (opcional, recomendado)
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# Instale as dependências
pip install fastapi uvicorn
